# Rupendran Manigandan — AI, Robotics & Interactive Worlds

Standalone static portfolio reconstructed from the saved live-site capture.

## Preview locally

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## Deploy to Vercel

1. Create a GitHub repository such as `Rupendran-Portfolio`.
2. Upload all files in this folder.
3. Sign in to Vercel with GitHub.
4. Choose **Add New → Project** and import the repository.
5. Framework preset: **Other**.
6. No build command is needed.
7. Deploy.
